# 0.2.0 打包与安装检查

日期：2026-10-26。此记录仅涉及格式、目录、索引和安装，不涉及投资表现或新增技能的模型行为通过率。

## 实际执行

- `scripts/validate.py`：12 个技能的 frontmatter、目录、来源记录和本地 Markdown 引用通过。
- skill-creator 的 `quick_validate.py`：12 个技能逐项通过。
- `scripts/build_index.py --check`：12 个技能、4 个包与实际元数据一致。
- 负向检查：修改描述后能拒绝旧索引；包引用不存在的技能时能拒绝生成。
- GitHub workflow 与两个 Issue 表单通过 YAML 解析；封面通过 SVG XML 解析。
- Skills CLI 从当前本地源码识别 12 个技能，在隔离临时目录把 `munger-inversion`、
  `soros-reflexivity` 同时安装到 Codex 和 Claude Code 的项目目录。

安装使用多技能、多客户端和 `--copy` 参数，与官方命令文档核对。源路径和临时路径省略；
没有改动用户全局技能目录。

## 解释范围

目录安装成功不证明客户端一定正确调用技能；检查通过不证明原始观点有预测优势。
新增六道行为题尚未做独立代理批量执行，不能宣称整个库通过行为测试。
