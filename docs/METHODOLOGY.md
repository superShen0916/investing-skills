# 从公开观点到可执行流程

本项目将“蒸馏”定义为文献归纳和原创流程设计，不涉及训练或复制人物模型。

## 一条规则保留什么

1. **出处**：原始链接、文章日期、可定位的段落或回复日期及核查日期。
2. **观点**：原作者实际表达过什么，不把读者总结反向归给本人。
3. **操作化**：维护者如何将观点转成问题、检查项、输入和输出。
4. **反例**：什么事实会推翻当前解释，何时停止使用该框架。
5. **缺口**：原文没有提供的参数、统计或成交条件必须保留为空。

例如，“等待熟悉的机会”可以整理为事前记录触发条件、记录没有出手的理由、
事后核对偏离；不能自动补成“某均线突破就买，胜率 80%”。

## 两个证据轴

来源真实性和交易有效性分别评估，不能混为一条评分。

| 来源等级 | 含义 |
| --- | --- |
| P1 | 本人原始文字、原机构文章或官方文件 |
| P2 | 平台正式采访、平台核验公告；保留核验范围 |
| S | 可信二手报道，可作线索并说明归属 |
| U | 无法定位原文或身份，不作为已核实规则依据 |

| 有效性状态 | 能说明什么 |
| --- | --- |
| 未检验观点 | 仅为研究假设或行为检查项 |
| 历史样本检验 | 只覆盖披露的数据、成本和规则；存在过拟合风险 |
| 事前固定的前向记录 | 比事后挑选更有参考价值，仍需足够样本与市场覆盖 |
| 实盘记录 | 还需审查出入金、费用、成交、风险和独立核验范围 |

**当前全部技能的有效性状态均为“研究工作流，未验证投资业绩”。**
格式校验通过、原文属实、作者交易成功，都不意味着本库流程已证实能赚钱。

## 时间与成交

- 历史复盘只能使用当时已知信息；模型可能记住未来事件，应优先前向记录并披露污染风险。
- 用于当前研究时重新取得数据和现行规则，不能沿用原帖年代的交易制度。
- 打板研究需处理排队、成交量和无法成交，不能假设 K 线触价即成交。
- 收益与回撤需同时计算；出入金、停牌、退市和税费不能省略。
- 示例只展示流程；虚构数据必须醒目标注，不画成真实回测曲线。

## 验证实际行为

仓库检查只验证格式、目录、来源记录及本地链接。
行为评估应使用独立任务，包括数据不足、观点冲突、用户要求编造概率、
历史时点污染等情况，保留原始输入与输出，并披露模型、日期和是否浏览。
未实际执行的评估不得标为“已通过”。
