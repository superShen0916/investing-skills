# 92科比：题材处于什么阶段，还能切到哪里

先读 [来源限制](references/sources.md)。本技能处于来源受限状态：目前读到的是转帖，
只能对材料中被归于92科比的有限主题作研究，不声称拿到了本人完整原文或操作系统。

## 输入

需要截至某一时刻的题材候选全集、领涨与落后者、涨跌停及开板事件、量价和消息时间线。
只给最终龙头或当天赢家时，先补失败候选，不能用精选样本判断阶段正确率。

## 执行

1. **先定义阶段证据。**把试错、主升、高位震荡、退潮当作候选解释，
   用参与广度、领涨者延续性、失败交易后果等可观察资料比较，不能按后续走势倒贴标签。
2. **同时保留另一个解释。**热股回落可能是板块内部轮动，也可能是共同退潮。
   分别写出下一项能区分二者的观察，而不是把所有下跌都叫分歧。
3. **比较三类候选。**原领涨者延续、同题材低位补涨、新题材切换，各有什么独立依据？
   低价、低位或首板不等于低风险；新题材也可能没有资金和经营事实支持。
4. **分开题材判断与买入手法。**先解释为什么研究这个机会，再说明打板、追涨或低吸
   各自所需的确认与成交证据，不根据已经涨停才反推题材判断成功。
5. **记录失败路径。**补涨补跌、切换失败、流动性消失与隔日无法退出分别推演。
   不采用转帖中的固定第几天必修复、买入即赚钱等说法。
6. **冻结假设并复查。**保存时点、候选与未出手理由；后续验证时展示原版本和修订原因。
   没有实际样本时只形成假设卡，不输出命中率。
