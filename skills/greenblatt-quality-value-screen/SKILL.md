# 乔尔·格林布拉特：质量与价格的筛选研究

读 [官方资料与公式范围](references/sources.md)。筛选结果是研究候选，
不是自动买入列表，也不能从书名推断能战胜市场。

## 输入

明确股票池、市场、研究日、财务数据口径和可得时间、价格、费用及拟研究的持有规则。
没有完整数据时可以审查方案；不能伪造完整市场的候选排名。

## 执行

1. **固定股票池与排除条件。**先决定可交易范围和行业处理，再看结果。
   官方筛选涉及美国股票，并排除金融和公用事业；迁移到其他市场时单列设计变更。
2. **同时看便宜与经营效率。**明确盈利收益率和资本回报率的定义、分母及会计调整。
   研究EBIT/企业价值与EBIT/有形经营资本时，标为所采用的公开公式口径，
   不把它说成当前网站完整专有实现，也不能用ROE或市盈率替换后仍称完全复现。
3. **处理不可比与异常。**负企业价值、非正经营资本、周期峰值利润、一次性收益
   可能产生失真排名；报告单独处理的理由，不静默删掉不利样本。
4. **给出可重建的排序。**各维度方向、并列规则、缺失值处理与联合排名都需明确。
   同时保留原始值，避免排名掩盖财务质量问题。没有精确原版参数就称改编研究。
5. **检查历史可得性。**按财报实际披露日而非报告期末使用数据；包含退市、停牌、
   失败公司及交易不可达情况。复权和分红须一致，防止幸存者与未来信息偏差。
6. **审查组合规则与成本。**先写分散、调仓、税费和容量假设，再评价结果。
   美国资料中的持有期限含当地税务背景，不能机械当作A股规则；没有实测就只输出设计。

## 反例与边界

- 排名前列来自周期高点或分母异常：回到经营研究，不能把排名当价值证明。
- 仅使用今天仍上市的公司回测过去：结果有样本偏差，不能据此报告有效性。
- 筛选网站也明确三年不保证结果；本技能没有经过投资业绩验证。
