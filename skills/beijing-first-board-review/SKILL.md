# 北京炒家：首板交易流程审查

把公开经验整理成可检验的流程，重点检查事前筛选与真实成交之间的差距。
这是维护者整理的研究技能，不是本人授权、完整战法或交易代理。
先读 [来源与归因](references/sources.md)，区分平台专访整理和本人自述。

## 输入与使用模式

先确认任务属于历史复盘、策略设计还是当日观察。
仅有每日收盘价时，可以研究日线特征，不能重建盘中排队与隔日快速退出。
优先取得以下字段；缺失项明确标记，不用想象补足：

| 输入 | 需要保留的证据 |
| --- | --- |
| 研究范围 | 市场、板块、证券类型、日期、首板的操作定义 |
| 候选全集 | 当时观察到的候选、排除标的及理由，含最终失败者 |
| 盘中信息 | 首次关注、触板、开板、回封、发单、撤单、成交时间 |
| 环境 | 涨停与失败情况、板块表现、前一日相关股票的后续表现 |
| 退出 | 事前规则、次日可交易信息、实际成交与费用 |
| 组合 | 同时持仓、资金暴露、行业与题材相关性 |

用户只提供成功标的时，做个案审查，说明缺少失败和放弃样本。
没有逐笔或盘口资料时，不能宣称某笔涨停排单一定成交。

## 可归因的历史经验

**2020 年平台专访整理：**盘中先关注候选、提前考虑如何下单，结合图形或板块联动，隔日较快处理持仓，并观察涨停情况与后续表现。
**2023 年本人讨论：**集中持仓与分散持仓在波动、速度和操作压力之间存在权衡。
专访中的制度预测、回撤标准和本人仓位数字都是当时个人观点，不能升级为通用标准。

**维护者操作化：**下面的事件审计、成交情景和样本外检验是本库设计。
不要把“图形好”“走弱”“持续性”当成已定义、已验证的信号。

## 执行流程

### 1. 核对市场制度

历史复盘采用事件当日有效的规则；当日观察重新查询交易所和券商的当前规定。
核对具体证券的涨跌幅、价格最小变动、交易时段、可卖时间、申报限制、费用与停牌状态。
不要假定所有 A 股证券的制度相同，也不要把过去一种涨幅制度迁移到其他市场。
记录数据时间、复权方式和时区；可交易价格不能用复权价代替。

### 2. 将主观词改写为待验证的定义

与用户约定首板、突破、板块联动、走弱的可观察口径和判定时刻。
没有口径时提供候选定义供研究选择，明确标为维护者假设，不称“北京炒家原版”。
定义必须只用判定时刻前的数据；用全日结果识别盘中候选属于前视偏差。
参数在查看验证期结果前冻结，修改后保留版本。

### 3. 重建候选到成交的事件链

每个候选都记录：何时进入观察、当时理由、计划触发条件、是否发单、能否成交。
把“看到了涨停”“以涨停价申报”“实际买到”分开。
检查扫入、排队、撤单的假设是否与可用数据精度一致。
没有队列资料时，同时给出不成交与可成交的情景，不默认有利成交。
保留触板失败、买到后开板、卖不出去等不利路径。

### 4. 独立检查隔日退出

在首笔买入前写出退出依据，不能依据次日最高价挑选卖点。
“走弱就出”若无操作定义，报告规则未闭合，不自动解释为某条均线或固定跌幅。
核对当时可卖数量、开盘跳空、流动性、跌停无法退出与实际成交价格。
同时报告持仓未结束的风险，不能把它从结果中删除。

### 5. 检查组合，而不只看单笔胜率

计算费后盈亏、单笔损失分布、持仓重叠和整个账户净值回撤。
区分按交易计胜率与按交易日计收益；多笔同题材交易不能视为独立证据。
分仓数量相同，也可能高度暴露于同一种风险。
不能引用本人自述的分仓回撤，保证用户能获得相同风险水平。

### 6. 决定是否值得继续验证

先将规则用于后续未参与调参的日期，保留全部候选与失败路径。
以合理费用、滑点、无法成交和容量限制做敏感性分析。
比较不交易和事先选定的可投资基准，写清风险与资金占用差异。
模拟盈利不等于实盘盈利；样本不足时只报告研究结果，不给未来盈利概率。

## 输出

1. **环境与制度：**市场、日期、规则来源、数据粒度及缺口。
2. **规则卡：**已定义条件、主观未定义项、版本与适用范围。
3. **事件表：**候选 → 触发 → 下单 → 成交 → 退出，每步附时间。
4. **组合结果：**费后收益、回撤、尾部损失、相关暴露与成交情景。
5. **反证与下一步：**最可能使结果消失的条件、应补的数据和验证计划。

当用户问“今天哪些能买”时，先取得当前数据；不足时可输出待观察条件，不编造即时盘口。
本 skill 的产出是研究结论或复盘表，不因调用而获得下单授权。

## 失效与反证

- 加入费用、滑点或不成交情景后优势消失：该实现尚未证明可交易。
- 效果仅集中在少数年份、市场阶段或少数极端赢家：报告依赖性，不宣称稳健。
- 规则只能事后解释、不能事前判断：降为描述性经验。
- 制度或市场参与者发生变化：重新验证，不引用历史名气替代证据。
- 候选全集、盘口或退出记录缺失：限定结论，不填补确定性收益曲线。
