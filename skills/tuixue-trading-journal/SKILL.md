# 退学炒股：交易日志与自我纠错

把模糊的“心态不好”拆成可追溯的行为与证据，帮助用户发现重复犯错的条件。
这是维护者依据公开文字整理的研究流程，不是本人授权、完整策略或人格模拟。
先读 [来源与归因](references/sources.md)，不要把流传语录当成本人原话。

## 先分清能做什么

- 可以检查一笔交易是否遵守事前计划，以及相似错误是否反复发生。
- 单凭一篇心得或几笔盈利，不能认定基础策略有正期望。
- 纪律改善、策略有效、最终赚钱是三个不同问题，分别报告。
- 本 skill 不提供自动交易流程；用户请求买卖建议时，仍需独立分析标的与当前环境。

## 输入

接受一笔交易、一个周期的完整交易表，或尚未执行的交易计划。
优先使用以下材料；缺少内容可以继续，但标记为“未知”，不要替用户补写动机：

| 材料 | 最少要知道什么 |
| --- | --- |
| 时间 | 决策、下单、成交、复盘各自发生于何时 |
| 事前计划 | 为什么参与，哪种证据会推翻判断，计划如何退出 |
| 行为记录 | 实际买卖、仓位变化、临时改计划及当时理由 |
| 心理自述 | 是否看到别人赚钱、刚连续获利、刚发生较大亏损 |
| 结果 | 成交与费用，尚未结束的持仓单独列示 |

不索取账户密码。交易记录可去除姓名、账号等与分析无关的信息。
用户只给一张盈亏截图时，先输出可核实部分和最关键的补充字段。

## 来源中的观点与本库的改写

**本人公开观点：**2017 年 2 月 22 日回复提醒留意踏空、连续成功后自信膨胀、亏损后急于扳本三类情境。
2017 年 2 月 20 日回复描述了盈利后扩大自信、冲动操作、随后大亏的循环。
这些是个人观察，不是对用户心理的诊断，也不是经过统计验证的预测变量。

**维护者操作化：**下面的时间线、行为标签和复盘表由本库提出。
它们用于检验记录，不代表退学炒股使用了相同表格、阈值或评分。

## 执行流程

### 1. 冻结当时能知道的信息

将材料拆为“下单前可见”“持仓期间新增”“事后才知道”。
有原始时间戳就引用；只有回忆就注明，不能将事后解释当成事前计划。
保留原始计划，后续修正另起一条，避免用新理由覆盖旧理由。
不要因为卖出后上涨，就倒推当时的卖出一定错误。

### 2. 找到行为变化，不猜测内心

检查三种情境是否与以下可观察行为同时出现：

- 原计划之外加仓、频繁开仓，或转向原本不研究的交易类型。
- 没有新证据却放宽失效条件，或为了“赚回亏损”延长持有。
- 因他人收益截图临时追入，且无法说明独立依据。

区分“用户明确自述”“记录支持的推断”“证据不足”。
出现情绪并不自动构成错误；要说明它是否改变了规则或风险暴露。

### 3. 分别评价三件事

| 维度 | 检查问题 |
| --- | --- |
| 判断质量 | 逻辑是否可证伪？当时的信息是否支持？是否忽略反证？ |
| 执行质量 | 是否按计划行动？调整是否有新证据？是否能实际成交？ |
| 盈亏结果 | 扣除费用后怎样？是否依赖偶发事件或市场普涨？ |

允许“执行合规但亏损”和“违规但盈利”同时存在。
事前计划若本身不合理，按计划执行也不能证明决策好。
没有完整样本时，不输出胜率、策略有效性或盈利概率。

### 4. 用完整样本检验重复模式

有周期数据时，包含全部交易、空仓期与未实现盈亏，并记录筛选口径。
比较有无冲动标签时的仓位、换手、费后结果和尾部亏损，报告样本数。
分组可能同时受市场状态、标的类型和仓位影响，不宣称情绪导致亏损。
用户只给失败交易时，可以识别问题，不能估计它的发生率或总体影响。

### 5. 提出一个可检验的改进

只针对证据最强的问题提出下一轮实验，例如：下单前留下独立理由和失效条件。
写明适用情境、观察字段与复查日期；不要随意规定统一冷静期或止损比例。
改进是否有效，以后续完整记录检验，不能由一句“增强纪律”完成闭环。

## 输出

按用户材料规模给出简短报告，至少包含：

1. **事实时间线：**计划、行动、后续信息与结果。
2. **行为证据：**支持哪种模式、依据在哪、哪些仅是推断。
3. **分开评价：**判断 / 执行 / 结果，逐项说明不确定性。
4. **反证：**最可能推翻当前解释的材料。
5. **下一次实验：**一项改进、记录字段、复查条件。

引用公开观点时链接原帖；引用用户记录时使用其提供的行号或时间。
涉及今天的交易可行性，重新取得最新行情和交易所规则，标明时间与市场。
仅复盘历史行为时，不必把当前行情混入当年的判断。

## 失效与反证

- 原始计划缺失：只能分析事后自述，不能判断是否违背计划。
- 情绪标签来自盈亏结果倒推：撤销标签，重新检查事前记录。
- 纪律改善但费后表现未改善：检查基础策略，不能继续归咎于“不够自律”。
- 只挑成功案例或只挑亏损案例：保留个案结论，撤回总体推断。
- 当前制度、流动性与历史不同：保留纠错思路，重新检验策略适用性。
