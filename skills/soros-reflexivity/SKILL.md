# 索罗斯：价格是否改变了故事本身

先读 [来源与归因](references/sources.md)。研究参与者看法如何影响行为，行为又如何改变现实。
这是公开思想启发的因果假设审查，不是索罗斯本人观点模拟或择时系统。

## 输入

确定市场、公司或主题、分析时点、用户主张的机制和现有证据。
区分价格、舆论、融资条件、经营数据及其时间顺序；没有行为数据时只列待验证假设。
当前研究重新取证，历史研究只使用当时可知材料。

## 执行

1. **区分三类东西。**可观察的事实、参与者声称相信的叙事、维护者推断的动机。
   价格上涨不能独自证明所有人看好，媒体热度不能代表资本已经采取行动。
2. **画出具体反馈链。**例如“估值提高 → 融资更容易 → 扩张加速 → 报告增长改善 →
   乐观叙事增强”。每条箭头分别找证据和时滞；这是本库示例，不是通用因果定律。
3. **比较单向解释。**观察是否只由订单、成本、政策或利率等外部变化驱动，
   而没有价格反馈到经营的机制。只有同步涨跌时，不能宣称已证实反身性。
4. **检验自我强化的约束。**哪些资金、抵押品、融资、盈利或制度条件必须持续成立？
   什么能打断链条？解释断点如何传导，而不只写“情绪转冷”。
5. **同时保留相反情景。**现实改善可能追上叙事，也可能进一步背离。
   写出区分这两种路径的后续证据，不把乐观自动称为泡沫。
6. **记录修正。**保留原始链条、证据时点与推翻条件；更新时说明哪条箭头失效。
   可证伪的机制研究不等于有可执行交易优势；若研究交易，另检验价格与成交。

## 输出

- 事实、叙事、推断三栏快照。
- 有方向的反馈链，每条箭头附来源、缺口与竞争解释。
- 强化条件、潜在断点、时滞和会改变判断的观察。
- 支持机制的证据强弱，以及目前不能判断的部分。

可以用简单文本箭头表示机制；只有资料支持时才估计量级。
没有校准数据时不赋予情景概率，不生成确定的顶部、底部或破裂日期。

## 归因与失效

本人讲座支持可错性、看法与事件相互影响及正负反馈的概念。
融资链、证据表与竞争解释属于维护者操作化，不声称原作者验证过该个案。
正反馈和负反馈描述强化与纠偏方向，不等于好事与坏事。

若关键箭头缺证、时间顺序不符或外部共同原因更有解释力，降级为待验证叙事。
即使确认一种泡沫机制，也不能推出立即卖出、做空或加杠杆；持续时间和交易成本仍可能未知。
