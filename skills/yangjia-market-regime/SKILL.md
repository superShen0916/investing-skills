# 炒股养家：市场阶段与应变假设

研究同一交易想法为什么在不同市场状态下可能表现不同，并事先写出判断错误时的应对。
这是维护者根据公开文章整理的研究流程，不是本人授权、完整心法或人格模拟。
先读 [来源与归因](references/sources.md)，尤其注意原文的日期与当时语境。

## 输入

先确定分析日期、市场、研究范围和决策周期。
当日研究要重新取得最新行情与规则，报告时间；离线练习只用截止时刻前的材料。
以下字段不是本人原版指标，而是本库建议的观测材料：

| 观察材料 | 作用 |
| --- | --- |
| 指数与市场宽度 | 区分少数权重上涨与较广泛的改善 |
| 领涨与落后群体 | 比较强势股、超跌股和新热点的表现 |
| 行情延续 | 观察当日走强能否持续，避免只看瞬时脉冲 |
| 成交与流动性 | 判断结果是否可交易，关注跳空与无法退出 |
| 候选与失败集合 | 保留同条件成功、失败和放弃案例 |
| 历史版本 | 当时判断、反证、新增信息和修改时间 |

没有市场宽度或板块数据时，允许做有限观察，但不能由一只股票推断全市场阶段。
用户未指定周期时，明确采用何种观察窗口，不把日内与数月状态混为一谈。

## 可归因的思想

**2011 年《论反弹》：**作者针对当时弱市，将反弹分为初、中、末阶段，讨论不同对象及背后的参与者心理，并承认阶段判断会错。
该文对当天市场的结论只属于 2011 年 6 月 14 日，不能作为今天的判断。
**2012 年《养家心法论股市》：**作者把市场情绪与风险收益比较联系起来。

原文没有提供完整客观分类器，也没有给每个阶段可复用的概率阈值。
不要从简短心法中推导“不设退出”“高位必须满仓”等用户操作。
**维护者操作化：**以下假设卡、竞争解释和冻结版本是本库设计，不冒充本人方法。

## 执行流程

### 1. 划定事实边界

给所有数据标记市场、时间、来源与可得时刻。
把价格、涨跌家数等观察事实，与“资金恐慌”“场外资金回流”等解释分开。
参与者动机通常不能从价格唯一推导；多个心理叙事可能解释同一走势。
没有资金行为证据时，用“与该解释一致”，不用“证明资金正在……”的语气。

### 2. 同时保留竞争解释

只有在弱市反弹确实是研究对象时，才使用初、中、末期框架。
至少保留另一个合理解释，如趋势延续下跌、短暂技术反弹或结构性分化。
原文框架无法解释当前市场时，输出“阶段未定”，不强行分三类。
“当前像末期”是研究假设，不等于“市场已经见底”。

### 3. 把阶段写成可推翻的假设卡

对主要假设分别记录：

| 字段 | 必须回答的问题 |
| --- | --- |
| 支持证据 | 截止现在有哪些可观察事实支持？ |
| 相反证据 | 哪些事实与判断不一致？ |
| 区分事件 | 接下来观察什么，能够区分竞争解释？ |
| 失效条件 | 哪种变化会迫使撤销或降低该判断？ |
| 适用对象 | 假设针对全市场、板块还是某一类股票？ |

阈值如需量化，标为研究者设定，写明依据，随后用独立时期检验。
不要将“连续下跌一段”“有爆发力”直接翻译为任意固定天数或指标。
没有校准样本时，用证据强弱和不确定性表达，不给伪精确的阶段概率。

### 4. 比较不同假设下的策略暴露

只讨论条件关系：某类研究对象若适合一种状态，遇到另一状态可能怎样失效。
检查判断错了时的流动性、集中风险、可卖时间和跳空损失。
“仍有应变优势”需要具体路径说明，不能作为不会亏损的同义词。
退出条件、仓位限制由用户目标或明确研究假设提供，不从心法口号反推。
有现有持仓时，区分已持有的风险审查与新增机会研究。

### 5. 记录更新，不重写过去

保留初始假设、当时证据与预定复查条件。
新信息出现后写新版本，说明改变了哪条判断和为什么。
阶段后来怎么走，与当时判断是否合理分别评价。
更新过快造成频繁翻转，也要计入操作成本与研究误差。

### 6. 验证阶段划分是否有用

用判定时刻前的数据打标签，不能用未来底部定义“末期”再回测。
冻结规则后，在未用于定义阶段的时期比较同一策略的费后结果。
保留分错阶段、未定阶段与无信号时期，报告各组样本量。
若只是解释行情而不能改善事前判断或风险管理，就报告其描述性价值。

## 输出

1. **截至何时：**市场、窗口、来源及数据不足之处。
2. **事实快照：**支持和反对弱市反弹框架的可观察变化。
3. **假设卡：**主要阶段、竞争解释、区分事件和失效条件。
4. **策略含义：**各情景的机会类型、错误判断的代价与待核实事项。
5. **更新记录：**下一次复查条件；历史复盘则列出当时与事后的区别。

## 失效与反证

- 同一组事实支持多个阶段且无法区分：保留未定状态。
- 分类依赖事后走势或事后重选指标：撤回预测性结论。
- 样本外分类频繁失灵或未改善费后结果：重新设计或放弃分类器。
- 制度、流动性或研究市场不同：不能直接迁移历史经验。
- 心理叙事没有可观察证据：保留为解释假设，不当成交易依据。
