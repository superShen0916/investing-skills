# ETF拯救世界：跟车之前先看自己的油箱

读 [本人文章及授权整理说明](references/sources.md)。把资金计划变成能承受不同市场路径的方案，
不直接复用长赢的历史品种、份数、交易指令或投顾服务。

## 输入

需要可投资资金、未来现金流、资金使用期限、已有资产、产品及用户给定的仓位边界。
讨论的是整个计划，而非只挑一笔买得漂亮的交易。缺资金信息时先审方案结构。

## 执行

1. **定义一份资金代表什么。**区分存量资金分份、每月新增资金、组合权重。
   份数不等于永远固定的金额，不能把不同建仓起点的跟投者当作同一个账户。
2. **列出上下限和触发规则。**什么时候增加、停止投入、减回目标仓位？
   说明规则来自用户、历史材料还是维护者研究方案；不用作者某期比例充当通用答案。
3. **模拟至少两条不利路径。**持续下跌导致资金耗尽；上涨过快而大量现金闲置。
   计算累计投入、剩余现金、目标偏离和潜在被迫退出，不只展示震荡赚钱路径。
4. **穿透资产分散。**不同指数可能重复持有相同公司或依赖同一地区和行业。
   同时看汇率、产品折溢价、申赎限制与实际费用。
5. **区分再平衡与回本冲动。**再平衡有事先边界、目标与预算，
   不因为亏了就无限追加资金；盈利后减仓也会有继续上涨的机会成本。
6. **核查跟投的差异。**信号发布时刻、实际成交、到账资金、税费及账户起点不同，
   历史发车列表不能直接重建用户收益。计划改变时记录变更理由与生效日。
