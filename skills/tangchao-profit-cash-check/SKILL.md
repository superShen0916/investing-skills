# 唐朝／唐书房：利润与现金

先读[来源与归属边界](references/sources.md)。围绕问答整理中被归于唐朝的利润、持续性与资本投入前提编写。当前使用第三方镜像；原始归属未完全核对，不声称已读全部图书或本人完整估值法。

## 输入

企业至少若干期同口径报表和附注、业务解释、资本支出与营运资金资料、用户的盈利假设和估值日期。按行业选择适当口径，不强用单一现金模板。

## 执行

1. **先看适用边界。**说明企业利润结构、会计口径与未来经营能否被合理解释。重大重组、早期亏损、金融企业等不能机械套同一现金和利润倍数。

2. **把利润连回报表。**核对收入确认、应收与合同负债、存货、非经常损益和并表变化。异常比率先形成核查问题，不在缺少证据时指控造假。

3. **解释现金与利润差异。**将经营现金与利润差异追到营运资金、税费、非现金项目和业务周期。单年现金好不证明利润真实，单年现金弱也不自动证明利润虚假。

4. **审查持续性。**把销量、售价、利润率和竞争变化的依据拆开，区分景气高点、一次收益与可重复经营。不因过去增长就延长未来增长率。

5. **识别必要再投入。**从资本开支、研发和营运资金找维持经营与增长的需求；分不清维护与扩张投入时给出区间与缺口，不把全部利润当可分配现金。

6. **再决定能否估值。**只在前提可解释时构建保守、基准等情景，展示利润和投入假设变化的影响。缺关键输入时停在财报疑点表，不套固定三年、固定倍数或理财收益率。
