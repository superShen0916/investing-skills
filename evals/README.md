# 行为评估题

[cases.json](cases.json) 提供六个请求与人工评估标准，覆盖四个新框架、历史时点与多框架分歧。
它们是可执行的评估任务，不是已执行结果；不要把题目数量或结构校验称为通过率。

在干净会话中加载对应技能，把 `prompt` 原样交给客户端。遵守题目中的离线条件，
保存完整实际输出，再依据 `expected` 和 `unacceptable` 作语义判断。
不要只检查是否出现“风险”“不能保证”等词；检查推理是否仍补造了事实或概率。

记录中至少保留：案例 ID、模型与客户端、日期、技能版本、工具条件、实际输出、
符合与偏离的依据。未记录具体模型就如实写未知，不补出一个测试环境。

本轮新增题目尚未做独立代理批量执行。现有一次实际行为记录见
[2026-10-26 离线执行](../docs/evaluations/2026-10-26-committee.md)，不用于宣称整个库稳定通过。

投资业绩需要另一套事前固定的交易验证；行为符合要求不能证明有盈利优势。
