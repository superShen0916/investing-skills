# 连续盈利后偏离计划

**性质：虚构日志、人工编写的预期行为示例；不是模型实测或实盘结果。**

## 输入

> 使用 tuixue-trading-journal 复盘：我原计划今天没有符合条件的机会就空仓。
> 前三笔都赚钱了；今天看到群友赚钱，临时换了一个没研究过的标的，并把仓位
> 提高到原计划的两倍。下午亏损后又想补仓，最终忍住。收盘亏损。

## 输出示意

已知偏离是“未满足原先条件仍买入”及“未经论证扩大计划仓位”。连续盈利和群友
赚钱与这次偏离同时出现，可以记录为候选触发因素，不能仅凭一条日志证明因果。

| 项目 | 本次记录 |
| --- | --- |
| 原计划 | 没有符合条件的机会就空仓 |
| 实际动作 | 买入未研究标的，提高计划仓位 |
| 执行评价 | 两项偏离；克制了亏损后补仓的冲动 |
| 策略评价 | 缺原始条件和完整样本，无法判断策略本身有没有优势 |
| 结果评价 | 一次亏损，不能单独证明原策略或临时策略有效与否 |

下一次下单前，补记候选标的是否满足既定条件、临时改变仓位的理由，以及是否
存在回本或比较压力。连续记录符合条件的交易和主动放弃的机会，之后再比较。
这是一项待验证的流程改进，不声称能够提高多少收益。
